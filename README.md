# Marketplace Nepal

A multi-vendor online marketplace for independent Nepali fashion shops.
Instead of searching through dozens of Instagram and Facebook pages,
shoppers can browse many small shops in one place.

## The Problem
Small independent brands sell mostly through social media. Customers have to
find each shop separately, and sellers have to handle orders through DMs.

## How It Works
Browse by category → pick a shop → explore its storefront → choose an item type
(tops, bottoms, skirts, casual, partywear). Or search across all shops at once.

## Planned Features (MVP)
- [ ] Customer and seller accounts
- [ ] Sellers create a shop (name, logo, description, Instagram link)
- [ ] Sellers add products with photos, sizes, price, and stock
- [ ] Browse: Clothes → Shop → item type
- [ ] Search across all shops
- [ ] Cart and cash on delivery checkout
- [ ] Seller dashboard to view and update orders

## Tech Stack (planned)
- Backend: Java, Spring Boot
- Database: PostgreSQL
- Frontend: React (responsive, mobile first)
- Images: Cloudinary

## Status
Just getting started. Currently learning the stack and designing the screens.
